## Product Overview

JetArm is an AI-powered robotic arm developed by Hiwonder, designed for NVIDIA Jetson platforms. Featuring advanced vision processing, ROS integration, and intelligent control systems, JetArm provides a powerful platform for AI robotics research, education, and development.

## Branches

This repository contains six branches for different hardware and ROS versions:

### Jetson Nano
- **Jetson_nano_ros1** - ROS1 version for NVIDIA Jetson Nano
- **Jetson_nano_ros2** - ROS2 version for NVIDIA Jetson Nano

### Jetson Orin Nano
- **Jetson_Orin_ros1** - ROS1 version for NVIDIA Jetson Orin Nano
- **Jetson_Orin_ros2** - ROS2 version for NVIDIA Jetson Orin Nano

### Jetson Orin NX
- **Jetson_Orin_NX_ros1** - ROS1 version for NVIDIA Jetson Orin NX
- **Jetson_Orin_NX_ros2** - ROS2 version for NVIDIA Jetson Orin NX

## Key Features

### AI Vision Processing

- **Deep Learning Integration** - Powered by NVIDIA Jetson GPU acceleration
- **Object Detection** - Real-time object recognition and tracking
- **Visual Servoing** - Vision-guided robotic arm control
- **Image Processing** - Advanced computer vision algorithms

### ROS Integration

- **ROS1/ROS2 Support** - Compatible with both ROS versions
- **Modular Architecture** - Flexible and extensible design
- **Standard Interfaces** - ROS topics, services, and actions
- **Simulation Support** - Gazebo and RViz integration

### Robotic Arm Control

- **Inverse Kinematics** - Precise end-effector positioning
- **Motion Planning** - Collision-free trajectory generation
- **Gripper Control** - Intelligent grasping capabilities
- **Multi-DOF Control** - Multiple degrees of freedom

### Hardware Platforms

- **Jetson Nano** - Entry-level AI computing platform
- **Jetson Orin Nano** - Advanced AI computing with enhanced performance
- **Jetson Orin NX** - High-performance AI computing platform
- **High-Precision Servos** - Accurate and reliable motion control
- **Camera Integration** - Built-in vision system

## Getting Started

### Choose Your Branch

Select the appropriate branch based on your hardware and ROS version:

```bash
# For Jetson Nano with ROS1
git clone -b Jetson_nano_ros1 https://github.com/Hiwonder/JetArm.git

# For Jetson Nano with ROS2
git clone -b Jetson_nano_ros2 https://github.com/Hiwonder/JetArm.git

# For Jetson Orin Nano with ROS1
git clone -b Jetson_Orin_ros1 https://github.com/Hiwonder/JetArm.git

# For Jetson Orin Nano with ROS2
git clone -b Jetson_Orin_ros2 https://github.com/Hiwonder/JetArm.git

# For Jetson Orin NX with ROS1
git clone -b Jetson_Orin_NX_ros1 https://github.com/Hiwonder/JetArm.git

# For Jetson Orin NX with ROS2
git clone -b Jetson_Orin_NX_ros2 https://github.com/Hiwonder/JetArm.git
```

### Installation

Refer to the README in your selected branch for detailed installation instructions.
